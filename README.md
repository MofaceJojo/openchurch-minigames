# OpenChurch 小游戏合集

耶稣传教主题的轻量小游戏系列。网页 + 手机浏览器即开即玩,后续可移植微信小游戏。
**开发商:OpenChurch**(同 https://openchurch.cc)

## 结构约定

- **一个仓库,只有 `main` 分支,一个游戏一个文件夹。** 不为不同游戏开分支。
- 每个游戏 = 一个文件夹 + 一个自包含的 `index.html`(零依赖、零构建)。
- 根目录 `index.html` 是合集入口页,新游戏做完就在里面加一张卡片。
- 共享代码(计分、触屏输入、缩放等)**等第二个游戏真正需要时再抽**,不提前造引擎。

```
openchurch-minigames/
├── README.md
├── index.html          ← 合集入口页
└── shepherd-snake/     ← 牧者行列(贪吃蛇 · v1,画面待重做)
    └── index.html
```

## 设计红线(每个游戏都必须过)

0. **UI 一律纯英文**:项目不面向大陆,受众是海外玩家(与 openchurch.cc 同一拨人)。开发文档可中文,玩家看到的一切必须是英文。
1. **可读性第一**:大元素、高对比,一眼看清谁是谁。发布前先截图自检——看不清就重做,玩法再好也不行。
2. **画面必须明朗**:蓝天、暖色、笑脸。**不做阴暗压抑的画面**(夜景版 night-watch 因此被推翻重做)。受众是孩子和女性玩家。
3. **动作和音效要搞笑**:被消灭的东西要打着旋儿飞出去,失败要有放屁号,不要严肃的打击感。
2. **主题服务玩法**:传教主题要落在机制上(如:救到的信徒排队跟随牧师),不是贴皮。
3. 竖屏优先,触屏是一等输入,键盘是补充。
4. 单局 1~3 分钟,死了立刻能重来。

### 躲猫猫小镇 peekaboo-town 结构

```
peekaboo-town/
├── core.js     ← 场景生成(可复现随机)、伪装强度、命中判定、计时
├── render.js   ← 160×240 虚拟像素渲染,整数放大保持锐利
├── audio.js    ← 搞笑音效,纯 WebAudio 合成(无音频文件)
└── index.html  ← 网页外壳(提灯光标 + 点击 + 音效开关)
```

- 伪装算法:小鬼**直接穿环境色 + 一点色差**,差值随关卡缩小,后期几乎融为一体
- 唯一破绽:偶尔**探头**——瞪大白眼 + 吐舌头 + 抖两下,间隔随关卡拉长
- 点中后:原地挤扁 → 打着旋儿飞上天 + 拖小星星;底下的人蹦起来举手,头顶飘音符
- 点错:红波纹 + **NOPE!**
- 音效全是现算的:滑哨升空、放屁号(点错)、滑稽小号(过关)、下滑长号(失败)
- 藏身点在生成时已过滤出界坐标(否则小鬼会躲到屏幕外,那关永远过不了)

### 牧者行列 v2 结构

```
shepherd-snake/
├── core.js       ← 平台无关逻辑(关卡曲线/技能/移动闪现规则)
├── render.js     ← Canvas2D 渲染(两端共用,可爱风)
├── index.html    ← 网页外壳(键盘+触屏)
└── wechat/       ← 微信小游戏工程(game.js 外壳 + core/render 副本)
```

- 设计准则:**娱乐性 >> 难度**;1-40 关零压力(速度每 5 关升一档给爽感,200→136ms 封顶,之后不再用速度上难度),难度只在最后 10 关缓抬。
- 关卡规则:配额 10→20(41 关后冲 50);小恶魔永远站桩、最多 3 只(是地形不是威胁);第 5 关起每关 1 个技能星(Gather/Smite/Shield/Spirit/Be Still,每关限用 1 次);**30 关起大恶魔蛇登场和你比赛抢信徒**——抢到的信徒挂它尾巴上,撞它尾巴整段抢回,撞头即死,38/46 关起它步频变快。追自己尾巴是安全的(尾巴宽容)。数值全在 `core.js` 顶部函数里调。
- **改了 core.js / render.js 记得 `cp core.js render.js wechat/` 同步副本。**
- 微信版用微信开发者工具打开 `wechat/`(compileType: game),本机尚未安装该工具,未真机验证。
