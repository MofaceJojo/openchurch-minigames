# OpenChurch 小游戏合集

耶稣传教主题的轻量小游戏系列。网页 + 手机浏览器即开即玩,后续可移植微信小游戏。
**开发商:OpenChurch**(同 https://openchurch.cc)

## 结构约定

- **一个仓库,只有 `main` 分支,一个游戏一个文件夹。** 不为不同游戏开分支。
- 每个游戏 = 一个文件夹 + 一个自包含的 `index.html`(零依赖、零构建)。
- 根目录 `index.html` 是合集入口页,新游戏做完就在里面加一张卡片。
- 共享代码(计分、触屏输入、缩放等)**等第二个游戏真正需要时再抽**,不提前造引擎。

```
openchurch-minigames/
├── README.md
├── index.html          ← 合集入口页
└── shepherd-snake/     ← 牧者行列(贪吃蛇 · v1,画面待重做)
    └── index.html
```

## 设计红线(每个游戏都必须过)

1. **可读性第一**:大元素、高对比,一眼看清谁是谁。发布前先截图自检——看不清就重做,玩法再好也不行。
2. **主题服务玩法**:传教主题要落在机制上(如:救到的信徒排队跟随牧师),不是贴皮。
3. 竖屏优先,触屏是一等输入,键盘是补充。
4. 单局 1~3 分钟,死了立刻能重来。

### 牧者行列 v2 结构

```
shepherd-snake/
├── core.js       ← 平台无关逻辑(关卡曲线/技能/移动闪现规则)
├── render.js     ← Canvas2D 渲染(两端共用,可爱风)
├── index.html    ← 网页外壳(键盘+触屏)
└── wechat/       ← 微信小游戏工程(game.js 外壳 + core/render 副本)
```

- 关卡规则:配额 10→50;第 2 关起有小恶魔,每 5 关 +1;30 关起移动,40 关起闪现;第 10 关起每关 1 个技能星(呼召/圣火/护佑/灵体,每关限用 1 次)。数值全在 `core.js` 顶部函数里调。
- **改了 core.js / render.js 记得 `cp core.js render.js wechat/` 同步副本。**
- 微信版用微信开发者工具打开 `wechat/`(compileType: game),本机尚未安装该工具,未真机验证。
